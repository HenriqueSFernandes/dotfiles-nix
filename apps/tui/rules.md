# Global rules

## Communication
- Be concise and direct; no filler or restating the request.
- Flag uncertainty explicitly instead of guessing.

## Code
- Match the existing conventions of each repository; do not reformat unrelated code.
- Keep changes minimal and focused on the task at hand.
- Do not add comments unless asked.

## Verification
- Run the project's lint, typecheck, or test commands when they exist before considering work done.
- Never commit unless explicitly asked.
